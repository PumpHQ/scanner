# Pump HQ Scanner

The website for Pump HQ Scanner, a browser extension for Axiom's Pulse and Terminal's Trenches
that labels every coin by its dev's record. It runs on a Scanner key from Pump HQ on Whop.

Install it from the Chrome Web Store (works in Chrome, Brave and Edge):
https://chromewebstore.google.com/detail/olaljdjbkmfakgmmfbkncmfeclodajej

Install guide and FAQ: https://pumphq.github.io/scanner/
Privacy policy: https://pumphq.github.io/scanner/privacy.html

Read-only: it never touches your wallet, never signs anything and never trades. Not made by or
connected to Axiom, Terminal or pump.fun. Nothing here is financial advice.
